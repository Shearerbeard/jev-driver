# AGENTS.md - Project Guide

`CLAUDE.md` is this repo's single project guide (purpose, commands,
conventions, status). Read it first. This file exists so agents whose
loaders read `AGENTS.md` instead of `CLAUDE.md` still find it.

Canonical sources, in order:

- `README.md` - user-facing docs: the derive and IR surfaces, the
  strictness contract, make targets, live-smoke setup
- `CLAUDE.md` - agent-facing conventions, clippy scope notes, status
- `NEXT-SESSION.md` - current state and next steps (single roadmap)
